# Keipher Ross | Personal Website

A personal website that introduces me, shows my interests and skills, and showcases the projects I have built. I am a year 2 Information Technology student at T.A. Marryshow Community College, and I'm aiming to become a software engineer and cloud architect.

**Live site:** https://keipherross-glitch.github.io/KR-S-Personal-Website/

## Responsive Design Strategy

The site is made responsive for screens on mobile, tablet, and desktop devices.

- **Desktop:** text appears alongside images via Flexbox, and a two-column CSS grid design is used in the contact section.
- **Tablet (900px max width):** images, paddings, and hexagon border sizes are decreased, and the stacking occurs when the screen is 768px.
- **Mobile (600px max width):** navigation hides under the logo, all layouts switch to a single column layout, and images fit the entire screen.
- Images have a maximum size equal to 100%, and the viewport is defined for all pages.
- Animations are hidden for people who prefer not to see them.

## Reflection

Developing this website made me reflect on my actual skillset and values, and how to present them for visitors to interact with. My biggest challenges were in CSS and GitHub rather than HTML. In CSS, I struggled with background contrast, and my pictures had different proportions, so I had to crop them to a consistent size. The animations took the longest to add. On GitHub, I created a lowercase images folder because the live site could not find pictures when names used capital letters, since GitHub Pages is case sensitive, so I updated my HTML paths to match.

Working on a separate branch was new to me. It kept the live site safe while I redesigned, small commits with clear messages recorded my progress, and a Pull Request let me review everything before merging into main. With more time, I would add features, expand the Contact section and add another completed project to my Portfolio.
